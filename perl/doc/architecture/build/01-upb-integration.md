# UPB Build Integration

The Perl `Protobuf` module directly embeds the `upb` library source code, compiling it as part of the XS extension build process using `ExtUtils::MakeMaker`.

## Strategy: Shared Library Compilation

Instead of a static library, the project now uses a **shared library** (`libprotobufperl.$(DLEXT)`) to facilitate state sharing across multiple XS modules.

-   **Bazel Prerequisite:** Before running the Perl build, specific UPB C sources must be generated by Bazel.
-   **Source Files:** `Makefile.PL` gathers necessary `.c` files from `../upb/`, `../src/`, and Bazel-generated directories, plus core XS logic in `xs/`.
-   **Shared Library:** Generated object files are linked into `libprotobufperl.so`. This ensures that global state (like the Object Cache) is truly global across the `Protobuf::*` namespace.
-   **Visibility Control:** The build system utilizes a linker script (`libprotobufperl.map`) to restrict symbol visibility, exporting only the public `PerlUpb_*` and `upb_*` APIs to ensure ABI stability.
-   **Sanitizer Integration:** The build system supports AddressSanitizer (ASan), UndefinedBehaviorSanitizer (UBSan), and MemorySanitizer (MSan) via `USE_ASAN=1`, `USE_UBSAN=1`, and `USE_MSAN=1` environment variables.
-   **Benchmarking:** A `make bench` target automates the compilation and execution of C-level micro-benchmarks.

## Future Vision (Reach for Excellence)

-   **VPP-Style Vector Processing:** Leveraging SIMD (SSE4.1/AVX2) for bulk field validation and access. This targets line-rate performance for high-throughput stream processing.
-   **Zero-Copy SHM Transport:** Utilizing `tmpfs`-backed arenas for multi-process communication. By sharing memory segments instead of serializing/deserializing, we eliminate the primary bottleneck in high-performance IPC.
-   **Global Audit Trail:** Trace-level debugging and observability for arena and object lifecycles, enabling deep inspection of memory usage and object migration across interpreters.

## Advantages

-   **Bundling:** `upb` is self-contained.
-   **Version Control:** `upb` version is tied to the repo.
-   **Simplified User Build:** Standard Perl toolchain.

## Disadvantages

-   **Slower Compilation:** Compiling all UPB sources.

## Alternatives Considered

-   **Amalgamation:** Difficult to manage flags.
-   **Linking all objects into each .so:** Larger `.so` files.
-   **System libupb:** External dependency for users.

## Conclusion

Compiling UPB sources into a static library and linking the `XSMULTI`-generated XS modules against it is the current approach.
